# Default highlighter plugin

## Background

Default highlighter plugin — highlight.js as a `code` producer shipped with the shell and
listed by `lem init`, claiming its languages, so a new site highlights out of the box and
limulus.net's `<pre><code class="hljs">` markup is reproduced exactly (D42); `lem theme`
turning a highlight.js or `.tmTheme` theme into CSS. A syntect-in-wasm producer is a plugin
a site adds, paying its 2 MB only there
